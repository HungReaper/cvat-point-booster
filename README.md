# CVAT 3D Point Booster

Browser extension that improves point-cloud visibility and adds measurement
references in CVAT 3D.

## Install locally

1. Clone this repository or download its files.
2. In Chrome, open `chrome://extensions`.
3. Enable **Developer mode**, choose **Load unpacked**, and select this folder.
4. Open CVAT. Press **Alt+P** to show or hide the extension panel.

## Get the latest version

After cloning, run `git pull` from this folder to update to the latest version.
